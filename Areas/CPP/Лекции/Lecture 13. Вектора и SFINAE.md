## Вектора
#### От ручного выделения к векторам
```cpp
int* n = new int[10];
n[5] = 5;
// тут много кода
// какой сейчас размер у n?
// стереть крайний элемент?
// пуст ли теперь n?
// не забыть delete[]
```

vector<int> v(10);
v[5] = 5;
// тут много кода
size_t vsize = v.size();

if(v.empty()) { /* что-то */ }
