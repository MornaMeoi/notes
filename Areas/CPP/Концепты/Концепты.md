# 🧠 Концепты C++

Атомарные заметки: одна идея — один файл. Общие для всех курсов.
Вверх: [[CPP MOC]] · Шаблон: [[Concept]]

> [!tip] Когда заводить концепт
> Когда тема всплыла **второй раз** в другой лекции. Тогда у заметки сразу
> два бэклинка, и она оправдывает своё существование.
> Кандидаты по базовому курсу: RAII (L04 + L08), RTTI (L06 + L15), SFINAE (L12 + L13).

## Все концепты

```dataview
TABLE WITHOUT ID file.link AS "Концепт", status AS "Статус", file.mtime AS "Изменён"
FROM "Areas/CPP/Концепты"
WHERE file.name != "Концепты"
SORT file.name ASC
```

## Заготовки без содержания

```dataview
LIST
FROM "Areas/CPP/Концепты"
WHERE status = "stub" AND file.name != "Концепты"
```
